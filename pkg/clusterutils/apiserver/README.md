# API Server Updater

Package `clusterutils/apiserver` provides functionality for updating the static pod manifest of the Kubernetes API Server of [kind](https://kind.sigs.k8s.io/) control planes.

See package [setup/dns](../../setup/dns/) or the [service-provider-template](https://github.com/openmcp-project/service-provider-template) e2e test example usages to test webhook configurations in [OpenControlPlane](https://open-control-plane.io/).
